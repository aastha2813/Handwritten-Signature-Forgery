# Handwritten Signature Forgery Detection System

## Overview
The Handwritten Signature Forgery Detection System is a Python-based application that uses image processing and machine learning techniques to analyze handwritten signatures and identify potentially forged signatures.

## Features
- Handwritten signature image analysis
- Image preprocessing and feature extraction
- Signature similarity comparison
- Machine learning-based signature verification
- Sample signing video for demonstration

## Technologies Used
- Python
- OpenCV
- NumPy
- Scikit-image
- Scikit-learn
- Matplotlib
- Pillow
- Joblib

## Installation

### 1. Clone the Repository
```bash
git clone https://github.com/aastha2813/Handwritten-Signature-Forgery.git
cd Handwritten-Signature-Forgery
```

### 2. Install Dependencies
```bash
pip install opencv-python numpy scikit-image scikit-learn matplotlib pillow joblib
```

## How to Run

Run the main Python application:

```bash
python signature_forgery_detection.py
```

Follow the instructions displayed by the application.

## Dataset and Model
Large datasets, generated outputs, and trained model files are excluded from this GitHub repository. The required files must be available locally if the application depends on them.

## Disclaimer
This project is intended for educational and research purposes. Its predictions should not be treated as definitive proof of signature authenticity.
